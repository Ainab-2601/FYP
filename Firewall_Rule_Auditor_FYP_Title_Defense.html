Innovation

One finding is a warning. Two together are a way in.

Core idea: an any-any firewall rule on a host running outdated Apache is rated Critical, because together they form a realistic way in.

Combine the findings

Each is only Medium alone (illustrative).

Two separate Medium findings from different modules. Press Combine: correlation joins them by host and the result is Critical. This is the idea no single existing tool does.

RANDOM FOREST

Which host first?

Runs locally with scikit-learn. Table data, mixed features, no special hardware, and it shows what pushed a host up the list. A what-if view shows the effect of each fix.

INSIDER

Weaknesses, not accusations

Excess internal access, dormant accounts, unusual login hours and spikes. Names are pseudonymised.

Honest data: labelled public dataset or a documented simulated one, always stated. Simulated results are never presented as real-world accuracy.
Zero trust in one line: ID checked at every door, not only at reception. Random Forest is many simple decision trees voting. Training data is the hard part, so we state clearly which dataset we use.

Evaluation

Unseen test data. Precision, recall, F1-score and a confusion matrix, because compromised hosts are rare and accuracy alone can look good while missing them.

Each audit module is independent with its own parsers, so a new format or check never touches the rest.

Agile, one module per sprint. Object-oriented, module-based code. Evaluation: not accuracy alone.
